# Diary User Guide

Choose one of four focused diaries: Meri Dukaan, Mera Kaam, Meri Class, or Mere Kharche. Change the choice any time from Settings.

## Mere Kharche

Enter an amount, choose Chai/Nashta, Travel, Food, Mobile, or Other, select a date, and add an optional note. Other asks for a category name. The screen shows today, week, and month totals plus a category breakdown.

## Data

Entries stay on this device. Use browser storage protection in Settings and keep the browser data when moving between sessions.
